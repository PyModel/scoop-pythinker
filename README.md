# scoop-pythinker

Scoop bucket for [Pythinker Code](https://github.com/PyModel/pythinker-code).

```pwsh
scoop bucket add pythinker https://github.com/PyModel/scoop-pythinker
scoop install pythinker-code
```

This bucket is auto-updated by the
[scoop-bucket.yml](https://github.com/PyModel/pythinker-code/blob/main/.github/workflows/scoop-bucket.yml)
workflow on every semver release tag. Do not hand-edit `bucket/*` — your
edits will be overwritten on the next release.
